# Quantum Prognostics

Hybrid quantum–classical models for bearing fault diagnosis and remaining useful life (RUL) estimation.

## Highlights
- Benchmarks QSVM, QNN, VQC, QSVR and HQCNN against classical ML
- Bearing fault classification
- Remaining useful life (RUL) regression

## Tech Stack
QSVM · QNN · VQC · QSVR · HQCNN · Hybrid QML

## Publication
**Bearing Fault Diagnosis Using Quantum Machine Learning**, IEEE.
